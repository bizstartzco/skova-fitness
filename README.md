# Skova Fitness — website preview

Static two-page website concept for Skova Fitness (gym + shop). Preview at https://bizstartzco.github.io/skova-fitness/

- `index.html` — the gym site
- `shop.html` — supplements, gear and merch with a WhatsApp order bag
- `credits.html` — photo credits for the placeholder imagery
- `js/config.js` — all site data (hours, prices, timetable, coaches, products). `SHOW_SAMPLES = true` shows labelled sample data for the preview; set it to `false` before launch.

Placeholder athlete and product photos are stock (Freepik free licence, Wikimedia Commons); see `img/IMAGES.md` for licences and credits. They are to be replaced by the gym's own photography.
